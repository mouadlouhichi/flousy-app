# Original source imagery

`morocco-budget-flatlay-ai.png`, `modern-budget-desk-illustration.png`, `money-places-editorial-illustration.png`, and `savings-goal-editorial-illustration.png` are original, text-free editorial visuals generated for this SmartJib social kit. They are intentionally used only as supporting visuals. The generator applies a Forest & Lime duotone at composition time, then adds all claims, values, labels, and the current wallet mark deterministically.

The images must not be used to imply a real customer, bank, account, balance, or testimonial. They contain no user or product data.

Run the generator from the repository root to recreate the final upload-ready PNGs:

```bash
node scripts/generate-instagram-kit.mjs
```
