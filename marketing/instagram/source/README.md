# Original source imagery

`morocco-budget-flatlay-ai.png` is an original, text-free editorial still life generated for this SmartJib social kit. It is intentionally used only as a supporting visual in the welcome feed post and Story; all claims, values, labels, and brand marks are added deterministically by `scripts/generate-instagram-kit.mjs`.

The image must not be used to imply a real customer, bank, account, balance, or testimonial. It contains no user or product data.

Run the generator from the repository root to recreate the final upload-ready PNGs:

```bash
node scripts/generate-instagram-kit.mjs
```
