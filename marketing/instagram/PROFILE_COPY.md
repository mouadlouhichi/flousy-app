# SmartJib profile copy

## Recommended profile setup

| Instagram field | Recommended value | Notes |
| --- | --- | --- |
| Username | `smartjib.app` | Check availability first. Instagram usernames are case-insensitive. |
| Backup usernames | `smartjib`, `smartjib_app`, `smartjib.budget` | Choose the closest available option; do not add numbers unless necessary. |
| Name | `SmartJib | Budget & Money Tracker` | Uses searchable terms without losing the brand name. |
| Category | `Product/service` | Set the account to Professional → Business. Hide the visible label if it is visually noisy. |
| Website link | `https://smartjib.app/?utm_source=instagram&utm_medium=social&utm_campaign=launch` | Replace the domain only if the production URL changes. |
| Email button | `hello@smartjib.app` | Add only if someone is responsible for timely replies. |
| Avatar | `brand/smartjib-instagram-avatar-1080.png` | It is already centered for Instagram’s circular crop. |

## Primary bio — English

Use this as the initial account bio:

```text
Budget with purpose, not pressure. 💸
Needs • wants • savings
No bank connection • 12 currencies
↓ Try SmartJib
```

**Character count:** 110 including line breaks. It is safely within Instagram’s 150-character profile limit.

## Profile name / SEO variants

Keep the exact brand name first. Change the descriptive suffix only after testing what people search for.

1. `SmartJib | Budget & Money Tracker` **(recommended)**
2. `SmartJib | Budget Planner`
3. `SmartJib | Budget MAD`
4. `SmartJib | Budget & Savings`

## Three link-label options

Instagram’s link text may be auto-generated. If a custom label is available, use one of these:

- **Start your budget**
- **Try SmartJib free**
- **Plan your month**

Avoid “Download now” unless SmartJib is distributed in an app store. The current product is a web/PWA experience.

Post this under the launch post after it has been published:


## Saved reply snippets for DMs

Set these up in the Professional dashboard before promoting the page.

### Welcome

```text
Thanks for reaching out to SmartJib! We share simple, practical ways to plan needs, wants and savings. What would you like help with?
```

### What is SmartJib?

```text
SmartJib is a private, manual budget tracker. It separates what money is for from where it is held — for example, a rent budget in your bank account or cash in your wallet.
```

### Do you connect to banks?

```text
No. SmartJib does not connect to bank accounts or request bank credentials. You add the information you want to track.
```

### Support boundary

```text
We can help with SmartJib and general budgeting education here. For individualized financial, legal, tax or investment advice, please speak with a qualified professional in your area.
```
