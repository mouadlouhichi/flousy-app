# Editable SmartJib social templates

These SVGs are editable starter files for Figma, Adobe Illustrator, Affinity Designer, Sketch, or a browser-based SVG editor. Canva can import them as artwork; if Canva flattens an SVG, use it as a locked visual base and add fresh editable text above it.

| File | Use | Canvas |
| --- | --- | ---: |
| `feed-post-1080x1350.svg` | Single feed post or a carousel slide | 1080 × 1350 |
| `story-1080x1920.svg` | Story artwork, poll / question background | 1080 × 1920 |
| `reel-cover-1080x1920.svg` | Reel title card / thumbnail | 1080 × 1920 |
| `highlight-cover-1080x1920.svg` | Highlight cover | 1080 × 1920 |

## How to keep future content on-brand

1. Duplicate the appropriate SVG instead of editing the original template.
2. Replace the `SMARTJIB / 00` label with a sequence number or content pillar.
3. Keep the headline to one idea and 2–3 short lines.
4. In the feed template, replace the `LOGO` placeholder with `../brand/smartjib-logo-mark-transparent.png`. In the other templates, add the mark only when it supports the layout; do not crowd the headline.
5. Preserve the supplied margins and safe areas.
6. Export as **PNG** at the native pixel dimensions. Do not export a 1080 px design at a smaller size then upscale it.
7. Add a matching descriptive caption and alt text when posting.

## Recommended typography substitutions

- Instrument Sans → **Manrope ExtraBold**, **DM Sans Bold**, or **Inter Bold**
- JetBrains Mono → **IBM Plex Mono** or **Space Mono**
- Cairo (Arabic) → **Noto Sans Arabic**

See [`../BRAND_GUIDE.md`](../BRAND_GUIDE.md) for exact colors, voice, accessibility, and platform-safe areas.
